# Public Transport Yekaterinburg Bot

Telegram-бот на Python для общественного транспорта Екатеринбурга. Показывает, через сколько минут на остановку придут автобусы, трамваи и троллейбусы, и умеет строить маршруты между остановками. Данные берутся из API транспортного портала города.

## Установка

1. Установите Python 3.10 или новее. Сторонние пакеты не нужны, используется только стандартная библиотека.
2. Скопируйте `.env.example` в `.env` и впишите токен бота от [@BotFather](https://t.me/BotFather):

```
TELEGRAM_BOT_TOKEN=ваш_токен
```

3. Запустите `python telegram_bot.py`.

Файл `.env` в репозиторий не попадает. Никогда не публикуйте токен.

## О проекте

Изначально это был минимальный прототип для проверки API портала.

Файл `stationsdesc.txt` используется как слой пользовательских подписей:
- значок перед `id` определяет тип остановки, например `🚌` или `🚊`
- текст после `=` становится человекочитаемым названием в боте и CLI
- значение `none` означает пустую пользовательскую подпись, тогда используется портальное название

Остановки без закреплённых маршрутов скрываются из публичного поиска и выбора. Их список строится по локальному кэшу `.station_route_status.json`.

## Запуск

```bash
python main.py "УрФУ"
```

Если остановка неоднозначная, скрипт покажет список кандидатов:

```bash
python main.py "УрФУ" --station-id 1736
```

Чтобы заново скачать и обновить локальный кэш остановок:

```bash
python main.py "УрФУ" --refresh-cache
```

Чтобы разрешить поиск и показ скрытых остановок из CLI:

```bash
python main.py "АП-2" --include-archived
```

## Что делает скрипт

1. Загружает список остановок и кэширует его в `.stations_cache.json`.
2. Ищет ближайшие совпадения по названию.
3. Получает ближайшие прибытия через API портала.
4. Печатает результат в виде `маршрут -> через N минут`.

## Telegram-бот

Токен читается из локального файла `.env`.

Проверка токена:

```bash
python telegram_bot.py --check
```

Запуск бота:

```bash
python telegram_bot.py
```

Запуск бота со сбросом старых апдейтов:

```bash
python telegram_bot.py --drop-pending
```

## Что умеет бот

1. На обычный текст ищет остановку и показывает ближайшие прибытия.
2. Если остановка неоднозначная, присылает inline-кнопки с вариантами и кнопкой возврата к списку.
3. Понимает команду `/route` и пошагово просит точку A, затем точку B.
4. Дополнительно понимает текстовые запросы маршрута вида `от Цирк до УрФУ` или `Цирк -> УрФУ`.
5. Использует пользовательские подписи из `stationsdesc.txt`.
6. Скрывает из публичного каталога остановки без маршрутов.
7. Показывает в Telegram-меню `/route` и `/about`.

## Полезные утилиты

Экспорт всех остановок:

```bash
python export_stations.py --refresh-cache
```

Скрипт создаёт один файл: `all_stations.json`, отсортированный по `id`.

Посмотреть остановку по ID:

```bash
python lookup_station.py 1736
```

Обновить кэш публичных остановок и скрыть остановки без маршрутов:

```bash
python refresh_public_station_index.py
```

## Экспериментальный планировщик маршрутов

В проекте появился отдельный CLI-прототип `route_planner.py`.

Что он уже умеет:
1. Скачивает активные маршруты через `getRoutes.php` и `getRouteById.php`.
2. Собирает локальный граф по порядку остановок в `subroutes`.
3. Добавляет пешие переходы между близкими остановками.
4. Ищет статический маршрут `A -> B` с учётом штрафа за пересадки.

Что это пока не умеет:
1. Не использует realtime-прибытия для всех пересадок.
2. Не понимает обычные адреса, только остановки или координаты `lat,lng`.
3. Даёт приближённую оценку времени в пути, а не официальное расписание.

Первый запуск с построением route-каталога:

```bash
python route_planner.py "56.838011,60.597474" "56.843274,60.650964" --refresh-routes
```

Повторный запуск из локального кэша:

```bash
python route_planner.py "УрФУ" "Площадь 1905 года"
```
